####  KEY MAPPINGS

leader is SPACEBAR

## TERMINAL
<leader>th     -Toggle a floating terminal
<leader>th     -Toggle terminal below/horizontally
<leader>tv     -Toggle terminal right/vertically
F7                  -Toggle terminal

## RUN CODE
<leader>rc     -Run the current file
<leader>rp     -Run Project [you must be at root directory of the project]
<leader>rs     -Start Liveserver
<leader>rl     -List Liveserve

## BUFFERs
<leader>bc     -Close saved buffers only
<leader>bd     -Close current buffer 
<leader>bD     -Close all buffers exept the current one
<leader>bn     -Create a new buffer

## WINDOWS
\              -Split Window Vertically
S-\            -Split Window Horizontally

<leader>wd     -Close window
<leader>wD     -Close Other Windows

## CASE
ALt-]    -Turn selected words to UPPER case 
Alt-[    -Turn selected words to LOWER case
Alt-\    -Turn selected words to TITLE case
